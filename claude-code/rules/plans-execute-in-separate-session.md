# Plan approval is not a go signal

Do not start executing after ExitPlanMode is approved. The
user runs the plan in a separate session. End the planning
turn by reporting what the plan file now says, then stop.

**Why:** after plan approval I began the first work item
(filing contract files, writing a skill) and was interrupted
with "i will execute the plan is a different session". Plan
approval is acceptance of the document, not a go signal.

**How to apply:** when a planning turn ends, summarize the
decisions written to the plan file and stop there. Offer
nothing and start nothing. If the user wants execution in the
same session they will say so. Overrides the general "don't
end a turn on a plan, do the work now" default for this user.
Same instinct as [[never-run-build-serve-test-unprompted]] —
the user controls when work starts in their environment.
